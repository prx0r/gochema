# Rebirth source texts (pairs with the CLIPS.md canonical roster)

Non-blocked doctrinal texts fetched to pair with each school's clip. These are
the *arguments* the clips make — not the spoken video transcripts (those are
YouTube-IP-blocked from this box; see CLIPS.md). Public-domain / freely
licensed sources. Pairs each clip with the text it stands on.

| File | Source | Pairs with (clip) |
|---|---|---|
| `mn60.txt` | **MN 60** Āṇadaṅkova Sutta (dhammatalks.org, Thanissaro) | Early-Buddhism seat — **244hh "Is Belief in Rebirth Necessary?"** `sVc45SXDrEQ`. MN 60 IS the burden-of-proof/safe-bet sutta: the Buddha's pragmatic wager for accepting rebirth ("if there is no next world… if there is…"). This is the "burden-of-proof chain." |
| `milindapanha-rebirth-flame.txt` | **Milindapañha** III.5.5 (accesstoinsight, Kellner, public domain) | **The candle-flame HOOK.** Nāgasena to King Milinda: "if someone kindled one lamp from another… one does not transmigrate and one is reborn." The canonical neither-same-nor-another rebirth simile — the doctrinal source for the flame-lit-from-flame montage. |
| `chah-birth-and-death.txt` | **No Ajahn Chah** — BIRTH AND DEATH section (abhayagiri.org PDF) | Thai-forest seat — **Ajahn Chah "Birth & Death"** `5cTN2gcHwME`. "Our birth and death are just one thing"; "Why are we born? …so that we will not have to be born again." |
